# The editor is the homepage

The product's identity is "drop-in editor, no signup": a visitor who arrives at
`/` is immediately using the tool rather than reading a marketing pitch, so the
editor itself lives at the root and no landing page exists. `/pricing` carries
the marketing load (plans, AGPL note, GitHub links), and the smaller launch
surfaces (About, Docs, Privacy, 404) hang off a shared minimal footer. This was
a real trade-off — most launches put a hero/features landing at `/` and move
the app to `/app` — and it is the kind of decision a future contributor might
casually reverse. Revisit only if SEO or distribution becomes a goal, at which
point the editor moves and a landing page takes the root.
