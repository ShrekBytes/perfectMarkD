# Stack: pnpm monorepo — React+Vite SPA, Node+Hono, SQLite+Drizzle; markdown-it, KaTeX, Shiki, mermaid

pnpm monorepo with three packages: `apps/web` (React + Vite SPA, Tailwind, CodeMirror 6, Zustand), `packages/core` (framework-free ported engine), `apps/server` (Node + Hono + Drizzle ORM + SQLite). An SPA — not Next.js — because the product is a single editor screen with no SEO surface, and a static bundle + small API server fits a cheap VPS. One language (TypeScript) end to end lets the engine be shared verbatim. Library swaps from the plugin: markdown-it replaces Obsidian's renderer, KaTeX replaces MathJax (synchronous, print-perfect, no generated-CSS extraction), Shiki replaces Prism + hand-maintained `CODE_THEMES` (VS Code-grade theme catalog), mermaid stays. Hosting: Docker Compose on a single VPS behind Caddy. *(Hosting statement superseded by [ADR-0010](0010-deploy-on-own-machine-behind-cloudflare-tunnel.md): the Compose stack still holds, but it now runs on the Admin's own machine behind a Cloudflare Tunnel. The stack decision itself is unchanged.)*
