# 06 — Launch checklist

Status: ready-for-human
Blocked by: launch/01

**Precondition, not a tracked blocker:** the stack is live at the real domain. The verification half below — the crypto transaction, the browser matrix, the third-party request audit — runs against a deployed instance. That deployment is host work on the Admin's own machine rather than a project task, so it is not a ticket; it is recorded in [ADR-0010](../../../docs/adr/0010-deploy-on-own-machine-behind-cloudflare-tunnel.md) and the README's Deployment section. The two repo-side deliverables below — the admin runbook and the Privacy page's Cloudflare-edge disclosure — need no deployment and are actionable now.

End-to-end pass before announcement: test crypto payment (small real USDT-TRC20 + LTC transaction through Order → Verification → gates open → expiry → re-lock); browser matrix (Chrome/Edge/Firefox/Safari: preview, print, server export); 50 MB + page-cap boundaries; empty/error states; privacy posture verified (no content on disk, no content in logs, third-party request audit — including the Cloudflare edge the Cloudflare Tunnel now puts in the request path, and the Privacy page's copy matching it); AGPL source + license present in repo; docs accurate; admin runbook (verify a payment, reset a password, change a wallet) written in `docs/ops/`. Then: Show HN / Obsidian community / r/Markdown announcement drafts.

**AI prerequisites** (ai-transforms/08; the feature is absent until these are done, so run them before announcement if the launch includes AI Actions):

- [ ] `AI_API_KEY` is set in the deployment's environment (never in the settings table, a tracked file, or a log — ADR-0008); the API is restarted so the worker picks it up. Rotating the key is also a restart.
- [ ] A model is chosen with the provider's published rates in mind: price one AI Action off the provider's own numbers and weigh it against the plan's monthly AI Allowance and its price. (There is nothing to read in the panel for this any more — its cost readout was removed on 2026-09-28.)
- [ ] The caps are sized to that model's window — context window, output cap, and input cap — with the panel's published numbers from Test connection as the reference; a mismatch is surfaced as a warning, not corrected silently.
- [ ] Test connection has been run to completion against the chosen model, and its published window and output cap have been read (a model the endpoint does not know fails here rather than for the first user).
- [ ] The Privacy page still states what leaves the browser and what is never stored, and the Admin has confirmed the copy against the configured provider.
- [ ] The kill switch is left on (or off, deliberately): with no key or the flag off, no AI surface exists for anyone and no upsell appears.


**Accepts**: checklist document all-green with dates; runbooks committed.

## Comments

- **Implemented (2026-09-28); the checklist is deliberately not all-green.** The deliverable is [`docs/ops/launch-checklist.md`](../../../docs/ops/launch-checklist.md), written against the live instance at `perfectmarkd.00022000.xyz` (`/healthz` reports `0.1.0` / `93aa378`, matching `HEAD`; Umami answering at `/analytics`). Announcement drafts are in [`docs/ops/announcements.md`](../../../docs/ops/announcements.md), and README gained an Operations section linking the ops docs.
  **"All-green" is not reachable yet and was not faked.** The one launch blocker left is money: a real USDT-TRC20 and a real LTC transaction, end to end, cannot be verified without spending it. Firefox and Safari print geometry is also unverified — only Chrome-family was exercised, and Safari was never available. The checklist marks source-reads (📄) separately from live observations (✅) precisely because this ticket's premise is that the launch risks are invisible from the code, and a single green tick would have hidden which claims were only argued.
  What did hold, live: a zero-third-party-request audit across all seven public routes (fonts and analytics same-origin, `/signin` loads nothing from Google), the full preview engine (tables, Shiki, KaTeX, Mermaid across 5 pages), a self-contained print document whose `@page` is A4 with no `<script>` and no non-`data:` asset, the 50 MB body cap rejecting a 60 MB payload with 413, the >100-page preview guard firing at 167 pages, and graceful degradation for every malformed input tried — with an empty console throughout.
- **Two Admin-only items were wrongly reported as open, and are now closed.** The first draft of the checklist inferred live state from seeded defaults and got both wrong: it warned that the wallet addresses might be unset, and that AI Actions were "inert" because `DEFAULT_AI_PROVIDER_CONFIG` seeds `model: ''`. Both are seed defaults written once at seed time (`settings.ts:85`); the running values come from the settings table via `getAiProviderConfig(db)` and are only visible in `/admin`. The Admin confirmed on 2026-09-28 that **all three wallets are set** and that **AI Actions work** on `stealth/space-bunny-alpha`, with the API restarted, Test connection run to completion and its numbers read, the Privacy copy confirmed, and the kill switch deliberately on. Neither fact was discoverable from outside an Admin session, which is the point worth keeping: a code reading is not a deployment reading, and this ticket's whole premise is that the launch risks are invisible from the code.
- **The one AI prerequisite genuinely still open is the cost arithmetic**, and it is open *because* the model is not free. `stealth/space-bunny-alpha` is a paid model, so the worst case for one AI Action (60,000 input characters plus 16,000 output tokens) has to be weighed against the plan allowance (Pro 100, Premium 300) and price (Pro 3, Premium 7 USDT). The two free OpenRouter ids on `ai-transforms/08` would have made it moot. Worth doing before announcing.
  **Closed since, by removal rather than by use (2026-09-28).** The panel's "worst-case cost of one AI Action" readout is gone, along with the token rows and the per-million price Test connection reported, so nothing in the panel is left to weigh. Do the weighing off-panel against the provider's own published rates, or switch to one of the free ids above. Test connection's window, output cap, and cap-mismatch warnings stayed — that is still the signal worth a glance before announcing.
- **The admin runbook needed no work.** `docs/ops/admin.md` already covers all three named jobs (verify a payment, reset a password, change a wallet) plus the dead-mailbox escape hatch and the audit log, and matches the shipped panel. Verified by reading both; it is the `runbooks committed` half of Accepts and it was already satisfied.
- **Two real defects found and fixed, both documentation.** (1) ADR-0010 recorded a *no-transport-disclosure* decision (an interim 2026-09-24 edit) that the shipped Privacy page contradicts — commit `4b2bd64` had already added the Cloudflare-edge disclosure with tests pinning it, so the ADR and the page were both live and wrong. The ADR's trade-off paragraph is corrected, and the launch-chrome spec's status comment, which carried the same superseded decision, is corrected with it. (2) `BACKUP_STAGE` was absent from `.env.example` despite being used by `ops/backup.sh`, `ops/restore.sh`, `docs/ops/restore.md`, and the live `.env`; a commented line was added beside `BACKUP_ENABLED`/`BACKUP_REMOTE`. The second is `launch/12`'s territory but is a docs-accuracy defect, which is this ticket's job. A third, pre-existing: this ticket's own link to ADR-0010 used `../../` where the path needs `../../../`.
- **`billing/04` dropped from `Blocked by:`** — see the note below.

That is the claim ADR-0013 already forced the project to restate once for email, and it contradicted the Privacy page the drafts were promoting. Corrected in all three drafts to the distinction the page actually draws: no page *loads* anything from another company's server, and the three disclosed exceptions (Resend for email, a user-clicked Google redirect, and an AI Action — the only flow that ever ships Document content) are named instead of glossed.
