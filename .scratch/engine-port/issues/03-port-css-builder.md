# 03 — Port css-builder (minus MathJax/Prism machinery)

Status: resolved
Blocked by: engine-port/01, engine-port/02

Port `css-builder.ts` into `packages/core`: `buildDocCSS`, `buildCodeBlockCSS` (now theme-agnostic — Shiki emits its own colors at render time, so keep only pre/code base styling: background, font, ligatures), frame helpers, `mmToPx`, `resolvePageDims`, `escapeHTML`, `escapeCSSForStyle`, `bgImageCssProps`, `hexLuminance`, font resolvers. **Delete**: `CODE_THEMES`, `TOKEN_GROUP_CLASSES`, `getMathJaxCSS*`, `stripAtFontFaces`, `waitForMathJaxStylesheetStable`. `resolveImageUrl` becomes the injectable `AssetResolver` interface. Replace the Obsidian callout classes with GFM Alert classes (`markdown-alert-note` etc., per github-markdown rendering) keeping the existing visual design.

**Accepts**: pure functions, no DOM/Obsidian imports; unit tests for page dims + CSS shape.

## Comments

Implemented 2026-09-04 (this commit).

- `packages/core/src/css-builder.ts`: `mmToPx`, `resolvePageDims`, `escapeHTML`, `escapeCSSForStyle`, `bgImageCssProps`, `hexLuminance`, `resolveFont`, `resolveCodeFont`, `buildCodeBlockCSS`, `buildDocCSS`, plus the frame helpers `frameBorderCSS` + `buildFrameOverlayHTML` (ported from `export-modal.ts`). Only import is `./settings.js` — no DOM, no Obsidian. All listed deletions verified absent (`CODE_THEMES`, `TOKEN_GROUP_CLASSES`, `getMathJaxCSS*`, `stripAtFontFaces`, `waitForMathJaxStylesheetStable`, `resolveImageUrl`).
- `packages/core/src/assets.ts`: `AssetResolver = (ref: string) => string | undefined` per the parent spec's "interfaces to design (not port)". Given its own module (rather than css-builder) since the markdown renderer and export builder consume it too; exported from the package index.
- Theme-agnostic `buildCodeBlockCSS`: keeps the base `<pre>`/`<pre><code>` styling — settings-driven background, font family/size, ligatures, `white-space: pre-wrap`/`overflow-wrap` (layout-critical for the paginator), and `color: bodyColor` as the plain-code fallback (preserves the original "None (plain)" contract; Shiki's inline colors override where present at markdown-render time). No token rules, no theme palettes.
- GFM Alerts: Obsidian callout classes replaced with `markdown-alert` / `markdown-alert-title` (+ `title svg`) targeting the structure issue 04 will emit (`markdown-alert markdown-alert-note`, …). The five variant classes are deliberately not styled individually — the original gave every callout type the same doc-accent design, and styling the base `.markdown-alert` covers all variants. Visual design preserved value-for-value: 4px accent border + radii, `accent12` background + `accent22` inset ring, `accent28` title band with border-bottom, uppercase 0.8em/800 title, 15px stroked icon, 9px/14px content gutter, subtler nested blockquotes. GFM has no content-wrapper element, so the old `.callout-content` padding is reproduced structurally (container `padding: 0 14px 9px`, full-width title via negative margins, `title + *` margin-top 9px, `:last-child` margin-bottom 0). `!important` flags dropped (no Obsidian themes exist to defend against) along with the `.external-link`/`.copy-code-button` defense rules and `.callout-fold`/`.callout-title-inner` (no GFM counterpart; issue 04 strips copy buttons at render time).
- Frame helpers: `buildFrameOverlayEl` (DOM) intentionally not ported — apps/web builds its own overlay element from `frameBorderCSS`; `buildFrameOverlayHTML` serves the export path (issue 07).
- Two functions that were module-private in the original (`hexLuminance`, `buildCodeBlockCSS`) are exported — the ticket lists them as ported surface and tests need the seam.
- Tests: 40 in `css-builder.test.ts` (page dims incl. custom-mm rounding to A4, ≥1px clamp, A4 fallback, caller-owned orientation; escapes; bg image props; luminance; font resolvers; frame helpers; code-block base + theme-agnosticism; full `buildDocCSS` shape incl. heading scale, conditional rules, dark-table-header white text, RTL, GFM alerts, and absence of callout/token/MathJax/`!important` traces) + 1 for the `AssetResolver` seam. Red → green (TDD).
