# 08 — Engine regression suite (real-Chromium golden tests)

Status: resolved
Blocked by: engine-port/04, engine-port/05, engine-port/07

Playwright-driven test harness: load a fixture page in Chromium, run the full pipeline (`render → paginate → layouts → exportHTML`) over golden documents — long prose, table-heavy, list-heavy, code-heavy (each theme), math+mermaid, `///` breaks, custom page size, RTL, all 7 presets. Assert page counts, heading→page outline entries, and no-overflow checks (no node extends past content box). These tests protect the moat; plugin behavior is the reference implementation.

**Accepts**: suite runs in CI (headless Chromium), catches a deliberately-introduced pagination regression.

## Comments

Implemented 2026-09-08 (this commit).

- **Harness** (`packages/core/src/golden/harness.ts`): one shared Chromium for the whole suite. Core's *source* is esbuild-bundled once per run (browser platform — same transform the app's build does; no stale `dist/`) and served into the page through Playwright **route interception** at a fictional `https://golden.local/` origin — no dev server, no filesystem writes, no port races, and file:// module imports (blocked by Chromium's file-access policy, verified) never come into play. The web app's real mermaid hook (`apps/web/src/canvas/mermaid.ts`) and the KaTeX stylesheet (straight from the katex package, same file tsup copies to `dist/katex.css`) are served the same way, so golden runs exercise exactly what the app ships. One-time gotcha recorded for posterity: Playwright routes look up `new URL(url).pathname` — the registry key needs the leading `/`.
- **Golden documents** (`documents.ts`): long prose (24 sections, inline-splitter workout), 60-row table, 40-item OL + UL + nested lists, 120-line TS + 60-line bash fences, the feature matrix (KaTeX inline+display, mermaid, alert, task list, footnotes, table, strikethrough), `///` section breaks, custom landscape 148×210mm, Arabic RTL. Preset coverage: FEATURE_MATRIX under all 7 presets (presets derived via `Object.keys(PRESETS)` so the list can't drift); "code-heavy (each theme)": CODE_HEAVY under none/github-light/github-dark/solarized-light/dracula/tokyo-night.
- **Golden snapshots** (`goldens/*.snapshot.md`, 21 files): per document — page count, per-page node **signatures** (`OL[18@17]` = 18 items continuing at number 17; `TABLE[11r+th]` = 11 body rows with thead replicated; `PRE[37l]` = 37 lines; `H2 «text»`), the outline (heading→page), and measured per-page content heights. Signatures exist because tag-only digests were proven unable to see the OL-numbering regression (verified empirically — that's why they're this rich).
- **Invariants asserted outright, per document**: no node extends past its page's content box — measured twice: in the pipeline's own run and in a fresh `measureExport` layout of the export document (catches pagination-vs-export-positioning divergence). Plus per-document structural expectations (every split-table fragment carries `+th`, each `///` section starts on a fresh page with its H1, etc.).
- **Wiring**: own config `packages/core/playwright.vitest.config.ts` (single fork: one shared browser process, ordered golden writes for `-u`); scripts `test:golden` / `test:golden:update`; root vitest excludes `src/golden/**` (root suite stays browser-independent); CI step installs Playwright Chromium and runs the suite. New core devDeps: `@playwright/test`, `esbuild` (both already in the workspace via tsup/vite; core now declares them honestly).
- **Acceptance verified by deliberate sabotage** (protocol recorded in `packages/core/src/golden/README.md`): `HEIGHT_EPS` 2→200 → 13/15 goldens fail; dropping OL `start` continuity → golden fails (`OL[18]` vs `OL[18@17]`); dropping table thead replication → 3 tests fail incl. the structural `+th` assertion. A behavior-preserving off-by-one sabotage correctly did *not* fail — the suite measures behavior, not implementation.
- **Two-axis review findings fixed**: `SECTION_BREAKS` fixture spread-join bug (the reviewer proved section 2 was rendering 162 one-character paragraphs — fixed, goldens regenerated); mermaid now runs under all 7 presets (was default-only); code-theme coverage added; prettier-JSDoc-glitch in harness fixed; dead `PLAYWRIGHT=1` env removed; duplicated export-measurement loop deduplicated into one shared in-page source; `smoke.golden.test.ts` got its module header. Left as-is: `measureExport`'s second overflow pass (hardening beyond spec, kept deliberately); overflow check inspects top-level children of the content box (a descendant escaping its parent's rect is a parent-overflow scenario the paginator already guarantees against via same-box measurement).
